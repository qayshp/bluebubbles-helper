# Find My Generated Headers

This directory contains generated header output for the private `FindMy*.framework` images inspected for the Find My helper work.

## macOS 26.5.2 build 25F84

- `macOS-26.5.2-25F84/class-dump/`: headers emitted by `nygard/class-dump`.
- `macOS-26.5.2-25F84/ktool/`: headers emitted by `0cyn/ktool`.

These files were copied from the preserved raw inspection output in `docs/findmy-framework-inspection-raw/`.

Most of these private frameworks are Swift-heavy dyld-cache images, so the generated headers are sparse. See `docs/findmy-framework-inspection-macOS-26.5.2-25F84.md` and `docs/findmy-people-location-apis-macOS-15.7.7-24G720.md` for interpretation and API notes.
